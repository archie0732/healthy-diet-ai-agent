# 前言（精簡草稿 v0.2）

大型語言模型雖具備自然語言理解與生成能力，其參數知識仍受訓練資料與更新週期限制，難以確保回答所依據的資訊為最新、適用且可追溯。檢索增強生成（retrieval-augmented generation, RAG）透過在生成前取得外部證據，使模型能依據特定來源回答知識密集型問題（Lewis et al., 2020）。然而，RAG 的可靠性不只取決於語意相關性，也取決於證據是否仍然有效，以及是否符合查詢中的時間、族群與適用條件。

此問題在持續修訂的營養與健康指引中尤其重要。新版指引可能完全取代舊版建議，也可能只更新數值、族群或適用條件；部分舊版內容雖不適合作為現行建議，卻仍是回答歷史比較問題的必要證據。僅依語意相似度檢索，可能取回已被取代的內容；一律偏好最新文件，則可能遺漏指引演變及相容歷史資訊。近期時間感知檢索已開始處理過時文件干擾（Cao et al., 2026），但「較新」仍不必然等同於「最適合目前問題」。

無條件套用版本政策同樣具有風險。若所有查詢都保留或提升歷史證據，有限的前段檢索位置可能被較不相關的內容占用；若只保留最新版，又會犧牲跨版本問題的資訊完整性。因此，本研究的核心問題不是以版本感知方法全面取代新近性檢索，而是：**RAG 系統應在何種查詢情境下保留跨版本證據？**

本研究提出查詢意圖驅動的版本感知 RAG 框架。系統先判斷查詢是否明確要求歷史資訊、版本差異或建議變化；一般現行問題沿用新近性檢索，具跨版本意圖的問題則依據證據譜系與版本關係，共同保留歷史及現行內容。研究資料被切分為可追溯至來源與頁面的原子證據單元，並標記版本、譜系、必要證據及跨版本關係。實驗比較附加式、新近性及版本感知檢索，評估必要證據召回、歷史—現行共同覆蓋，以及陳舊或不安全證據命中。

為降低資料洩漏與結果導向調參，本研究採用可稽核的分階段流程。資料、政策與評估分區均以雜湊值凍結；比較系統使用相同候選池；檢索階段與密封標註分離；開發、驗證及一次性新鮮測試具有明確的資訊與執行限制；主要結果另由獨立程序重新計算。

本研究探討三項問題：（1）新近性檢索在現行、歷史及條件式查詢中存在哪些限制；（2）選擇性啟用版本政策能否提升跨版本證據覆蓋，同時維持一般現行問題的檢索表現；（3）候選召回、版本安全與證據完整性之間存在哪些取捨。主要貢獻包括提出查詢意圖驅動的版本感知架構、建立可執行的跨版本證據關係，以及設計具共享候選池、資料凍結、一次性測試與獨立重算的可重現評估流程。研究藉由正面與負面結果界定方法的適用範圍，為持續更新的健康知識庫提供可稽核的版本化證據檢索方法。
